## Summary of material findings

1. **No outright refutations** among the 70 claims in claims-other-1.json. Prices and free-tier limits for Resend, SES, Cloudflare,
   Postmark, Mailgun, SendGrid, MailerSend, WorkOS, Auth0, Clerk, Supabase and Firebase all matched the live pages on this check.
2. **Budget-relevant omission (O1):** the AWS **Free account plan auto-closes the account after 6 months** (or when credits run out)
   unless upgraded; credits are $100 + up to $100 earned. A public prototype should use the Paid account plan. Not stated in O1.
3. **Budget-relevant understatement (O1):** new SES accounts **default to Essentials ($0.16/1,000)** since 2026-07-21. O1 calls this an
   inference; the pricing page states it. The "a la carte" proposal requires cancelling the default plan. Cost impact at prototype volume is cents.
4. **NIST timeouts are SHOULD, not SHALL** (A1): AAL1 <= 30 days and AAL2 <= 24 h / 1 h idle are recommendations; only the email
   OOB prohibition is a SHALL NOT.
5. **Security Framework `kid`** (A2): MUST in key sets; not mandated in every JWT header. A2's body uses it correctly for the tool JWKS.
6. **Better Auth advisories** (A1): count of 10 in the window is right across all 4 pages, but one Critical is in `@better-auth/scim`,
   not `sso`; and 9 more (1 Critical SSRF in `@better-auth/sso`) landed on 31 May 2026. Cadence of serious advisories is high.
7. **Cloudflare Email preview also stores attachments** (O1 omits this). **Brightspace KB says "D2L does not yet support all aspects
   of the standard"** (A2 should carry this caveat). **Brightspace KB still mentions the Anonymous deployment setting**, confirming
   the author's conflict flag; the API docs are authoritative that it is always false.
8. **Wrong/insufficient URLs in claims file:** Postmark prices cite eu-privacy (prices are on /pricing); moodle-docker cites the Moodle
   docs page (licence/maintenance are on the GitHub API); jose push date is on the GitHub API, not npm. 1EdTech certification
   membership requirement is stated on the page (author marked unverified).
