## Summary

About 85 web fetches of official pages were made on 2026-10-11 (one per URL, plus a few focused
re-reads of the same page). Overall the three notes files hold up well. Nearly all cited claims match
the live pages. The problems found:

**Refuted / outdated (fix before the notes become project documents)**
1. **S0 says the Worker size limit is "3 MiB Free / 10 MiB Paid"** as a plain fact. Cloudflare's own
   limits page says 64 MiB uncompressed on both plans and "There is no compressed size limit". The
   3/10 MiB figure comes from OpenNext's docs, which look stale. H3H4 flags this conflict correctly;
   S0 does not.
2. **S0 says "Cloudflare today goes through `@opennextjs/cloudflare`".** This is outdated. Cloudflare
   now recommends vinext (beta) by default, and its feature table lists `proxy.ts` as Supported under
   vinext. NQ-S0-3 should be reworded: proxy.ts support is documented for vinext and still unstated
   for OpenNext.
3. **H3H4 calls Cloudflare Email Sending "Paid-only".** That is too strong. Sending to *verified
   destination addresses* is free on all plans. Only sending to arbitrary recipients needs Workers
   Paid. The practical conclusion still holds, because magic links go to arbitrary users.
4. **H1H2 gives the Porkbun .ca renewal as $11.60.** The page shows **$11.61** (regular price). A sale
   price is also live right now (register $8.66, renew $9.15). Porkbun never names the currency.

**Unverifiable (the cited page does not say it, or does not load)**
- React Router v8 "announced 2026-06-17". The cited docs page gives no date.
- "Data Localization Suite is Enterprise-only". The cited D1 page never mentions it.
- Cloud Run Tier 2 / idle min-instance rates, and Render's "$7 + $6". Both pricing pages still return
  no figures to WebFetch. Keep these **Unverified**.
- Cloudflare Registrar "at cost". The TLD policy page shows no prices and no at-cost statement.

**Right claim, wrong URL** (cite these URLs in the notes instead)
- Hyperdrive's 10-configs limit is on `/hyperdrive/platform/limits/`, not the pricing page.
- Cloud Run "request logs created automatically, cannot be disabled" is on `/run/docs/logging`, not
  `/logging/quotas`.
- "Render and Railway have no Canadian region" is on `render.com/docs/regions` and
  `docs.railway.com/reference/deployment-regions`.
- Email Sending "beta" is on `/email-service/`.
- Porkbun .com $11.08 is on `/tld/com`.

**Nuances to add**
- Next.js `middleware.ts` is deprecated, not removed.
- Prisma 8 is on `prisma@latest` (changelog dated 2026-08-28). Yet GitHub still tags every 8.0.0
  build as an rc pre-release (rc.17 on 08 Oct), so its maturity is ambiguous.
- Sentry's defaults are now described through the `dataCollection` option, not `sendDefaultPii`. By
  default it collects all categories, including the IP address.
- Fly's $2.19 price applies only in the iad and ewr regions.
- On Vercel, "Routing Middleware [is deployed] to all regions by default, regardless of your region
  settings". This could matter for data residency (§6). See PQ-FC-2.
- Workers Logs pricing changes on 2026-12-01. The H3 cost table should carry a caveat about this.

**No change to the recommendations is forced by this check.** The cost figures behind the <$5/month
comparisons are confirmed: Vercel Hobby allowances, Neon Free and Launch, Supabase Free and Pro,
Workers Free and Paid, D1, Hyperdrive, Durable Objects, Resend, Railway, Fly, and the GCP free tier.
The biggest budget caveat is currency. Vercel and Cloudflare state prices in USD (Neon's currency was not checked), so the $5 USD Workers
Paid minimum alone already meets or exceeds a $5 target (see PQ-FC-1).

### Proposed new open questions (for the owner; not in CONTRIBUTING §13 Q1–Q20)
These are refinements under Q3 (stack and hosting) and §6. They are proposals and close nothing.
- **PQ-FC-1, currency of the budget.** Is the "<$5/month" target in USD or CAD, and does it include
  tax? Vercel ("All prices shown are in USD", hobby page) and Cloudflare price in USD; Neon not checked. Workers Paid is "a minimum charge of $5 USD per month"
  (https://developers.cloudflare.com/workers/platform/pricing/, checked 2026-10-11).
- **PQ-FC-2, Vercel edge execution and residency.** Vercel says it "deploys Routing Middleware to all
  regions by default, regardless of your region settings"
  (https://vercel.com/docs/functions/configuring-functions/region, checked 2026-10-11). Does a Next.js
  16 `proxy.ts` (or `middleware.ts`) on Vercel run as Routing Middleware outside `yul1`? If so, is
  that acceptable under §6? **Unverified**, needs a test deployment or Vercel docs.
- **PQ-FC-3, vendor agreements for the prototype.** Vercel's DPA covers only Pro and Enterprise
  (https://vercel.com/legal/dpa, checked 2026-10-11). Firebase Hosting "is not covered by Google Cloud
  Terms of Service" (https://docs.cloud.google.com/run/docs/mapping-custom-domains, checked 2026-10-11).
  Is a signed DPA needed before real UW users sign in? This may overlap with questions the notes
  already raise. If so, merge them.
