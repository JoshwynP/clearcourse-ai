# ClearCourse AI

A learning-transparency platform for higher education. It provides Course and Assignment AI Cards,
an anonymous upvotable question board, optional process-transparency bonuses, a classroom
presentation mode and privacy-preserving participation verification. The initial target is the
University of Waterloo.

**Status:** Scaffolding only. The tech stack is not yet decided.
